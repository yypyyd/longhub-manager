# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io),
certificate by [SignPath Foundation](https://signpath.org).

## Scope

Only LongHub Manager artifacts built from this repository may be submitted for
signing. Cloud Skill implementations, Cloud API services, plugins, command-line
clients, third-party binaries and artifacts built from any other repository are
outside this policy and must not be signed with the LongHub Manager project.

The signed Windows release contains:

- `LongHubManager.exe`, built from the Go source in this repository.
- `LongHub-Manager-Setup-<version>.exe`, built by NSIS from the verified Manager
  executable and `release-config.json`.
- `Uninstall.exe`, generated by NSIS as part of the installer.

## Build provenance

Release artifacts are built by the public GitHub Actions workflow in
`.github/workflows/windows-release.yml`. The workflow checks out an immutable
commit, runs all Go tests, builds on a hosted Windows runner, records SHA-256 and
publishes the unsigned candidate for SignPath processing. Release builds do not
accept arbitrary scripts or binary inputs. The Windows resource generator is an
open-source Go tool pinned by version and checksum in `go.mod` and `go.sum`.

Every production signing request requires manual approval. Signed outputs are
verified for Authenticode status, product metadata, version, publisher,
timestamp, size and SHA-256 before publication.

## Team roles

- Committer and reviewer: [yypyyd](https://github.com/yypyyd)
- Signing approver: [yypyyd](https://github.com/yypyyd)

Repository and SignPath access must use multi-factor authentication. Changes
from any other contributor require review by the maintainer. Build workflow,
installer and signing-policy changes receive the same review as application
source changes.

## User privacy and system changes

The [privacy policy](PRIVACY.md) describes network and local-data behavior.
LongHub Manager announces installation and uninstallation through its Windows
installer. Operations that install OpenClaw, change Gateway startup, restore a
backup or apply a Manager update require an explicit user action.

Security reports may be submitted through the repository's private security
advisory feature. Suspected policy violations will be investigated and reported
to SignPath Foundation when required by its terms.
