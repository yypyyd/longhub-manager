# Security policy

Please report vulnerabilities through this repository's **Security** tab by
opening a private vulnerability report. Do not place exploit details,
credentials, personal data or unredacted diagnostic archives in a public issue.

The maintainer will acknowledge a complete report, investigate affected
versions and coordinate a release before public disclosure when appropriate.
Reports involving release artifacts, hashes or the update trust chain receive
the same private investigation before disclosure.

LongHub Manager has no Cloud Skill credentials or account authentication.
Relevant trust boundaries include the loopback bearer, native OpenClaw process
control, configuration backup paths and the cryptographically verified Manager
update pipeline.
